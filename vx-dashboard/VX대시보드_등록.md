- **growth_pack_50/100/150** — "용병단의 다음 도약을 위한 성장 지원 패키지. 계정당 한 번만 구매할 수 있습니다." (2026-08-26 단장 확정: 스테이지 도달 트리거·3일 한정 폐기, 상점 상시 노출. 대시보드에는 각각 Lifetime Limit 1)
- **premium_pack** — "전투와 방치가 영구히 3배속이 되고, 광고 버튼을 누르면 광고 시청 없이 즉시 보상이 지급됩니다. 매일 다이아 100이 우편으로 도착합니다. (광고 일일 횟수 제한은 동일)"
- **pass_premium_s1** — "시즌 패스 유료 트랙을 해금합니다. 이미 지난 티어의 프리미엄 보상도 구매 즉시 전부 받을 수 있습니다."
  · **시즌마다 새 SKU 를 등록한다** (`pass_premium_s1` → 시즌 2 때 `pass_premium_s2`), 각각 **Lifetime Limit 1**.
  패스는 42일마다 다시 사는 상품이라 상한을 안 걸면 한 시즌에 두 번·세 번 결제가 가능하다 —
  지금 막는 건 클라 UI 하나뿐이라(세이브를 지우면 버튼이 되살아난다) 대시보드 쪽 상한이 실제 방어선이다.
  Period Limit(일/주/월)은 42일 시즌과 맞지 않아 쓰면 안 된다: 월 1회로 걸면 시즌 경계가 달 중간에 오는
  순간 정당한 구매까지 막힌다.

### 구매 제한 (Purchase Constraints)

| 상품 | Lifetime Limit | 그 밖 |
|---|---|---|
| `pack_s` ~ `pack_xxl` | 없음 | 반복 구매 상품 |
| `premium_pack` | **1** | 영구 해금이라 두 번 사면 두 번째는 효과 없이 돈만 나간다 |
| `starter_pack` | **1** | "생성 후 7일"은 계정마다 기준이 달라 대시보드의 Time-Limited(고정 날짜)로 못 건다 — 클라가 노출을 막는다 |
| `growth_pack_50` / `_100` / `_150` | **각 1** | 상시 판매라 다른 제약 불필요 |
| `pass_premium_s{N}` | **1** | 시즌마다 새 SKU. Period Limit 은 쓰지 말 것 (아래 설명) |

Period Limit(일/주/월)은 어느 상품에도 쓰지 않는다 — 유일하게 반복 구매하는
패스가 42일 주기라 일/주/월 어디에도 안 맞고, 월 1회로 걸면 시즌 경계가 달
중간에 오는 순간 정당한 구매까지 막힌다.

**Metadata (JSON) 는 전부 비운다.** 지급 내용의 단일 소스는 게임 데이터
(`shop.json > packages[].grant`)고, 클라가 product id 만 보고 거기서 꺼내
지급한다 — 대시보드 메타데이터를 읽는 코드는 없다. 양쪽에 적으면 한쪽만 고쳤을 때
어느 게 진짜인지 판단할 근거가 사라진다. (서버가 결제를 검증하고 직접 지급하게
되면 그때는 서버가 게임 JSON 을 못 읽으므로 메타데이터가 필요해진다 — 그 시점에 채운다.)

### 이미지 상태

- `pack_s`~`pack_xxl`: 기존 SHOP-D1~D5 그대로 (검수 완료 아트).

## 2. 광고 지면 (Rewarded Ads)

대시보드에 등록할 placement id — `game/src/net/ads.js` 와 이름이 정확히 같아야 한다.

| Placement ID | 위치 | 보상 | 일일 상한 |
|---|---|---|---|
| `idle_double` | 방치 보상 창 — "2배 받기" | 쌓인 방치 골드 ×2 | 상한 없음 (보상이 쌓여야 의미) |
| `instant_claim` | 방치 보상 창 — 즉시 수령 | 2시간분 골드 즉시 지급 | 2회/일 (무료 2회 소진 후) |
| `arena_entries` | 아레나 → 입장권 [+] 구매 창 | 아레나 입장권 +3 | 1회/일 |

미구현(문구만 존재): 던전 열쇠 "광고 +1" — `dungeons.json > entry.adBonus` 데이터는 있으나 재생 버튼이 아직 없다. 지면을 미리 등록한다면 `dungeon_keys` 제안.

`adfree_pack` 구매자는 위 지면 전부 광고 재생 없이 즉시 보상 (횟수 차감은 동일).
