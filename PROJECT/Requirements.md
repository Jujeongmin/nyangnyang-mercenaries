# Requirements — 냥냥 용병단

## 장르
켜두면 알아서 도는 방치형 키우기. 플레이어의 선택은 **편성과 투자**다.

## 지켜야 하는 것
- **확률 공시**: 게임산업법(2024.3) 의무. `gacha.json` 이 단일 소스이며 화면에
  표시하는 표와 **실제 뽑기가 같은 값을 써야 한다**. 예전에 뽑기가 자체 공식을
  굴려 공시표와 어긋난 적이 있다 — 그런 분기를 다시 만들지 말 것.
- **다국어 5종**: 한국어·English·日本語·简体中文·繁體中文. 새 문구는 4개 사전에
  같이 넣는다. 그림 안에 글자를 굽지 않는다.
- **세로 모바일**: 360~430px 폭이 기준. PC 에서는 화면 높이에 맞춰 넓어진다.

## 밸런스 원칙
- 해금 순서는 **퀘스트 진행도**가 기준이다. 전투력(CP)으로 열면 뽑기 운이
  순서를 흔든다.
- 숫자 단위는 앞 단위가 10만에 닿을 때 넘어간다 (`core/fmt.js`).
