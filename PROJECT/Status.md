## 서버
루트 `server.js` 에 랭킹·프로필·아레나 표본·친구·연합·연합 보스·채팅·결제가
들어 있다. 클라는 `net/live.js` 가 읽는다.

**남은 것은 접속 한 줄이다.** 호스트가 게임서버 객체를 어떤 전역 이름으로
넣는지 확인된 적이 없어서, `live.js > findServer()` 가 `remoteFunction` 을 가진
객체를 전역에서 찾는다. 부팅 때 콘솔에 결과를 남긴다:

```
[냥냥] gameserver 연결됨        ← 붙었다
[냥냥] gameserver 없음 (데모로 동작)  ← 못 찾았다. 채팅·랭킹·연합이 데모로 돈다
```

배포본에서 이 줄이 "없음" 이면, 그 환경의 전역 이름을 찾아 `findServer()` 의
후보 목록에 넣으면 된다.
