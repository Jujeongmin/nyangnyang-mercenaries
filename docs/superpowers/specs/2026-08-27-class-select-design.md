# 시작 직업 선택 (2026-08-27)

## 규칙
`S.promoClass === null` 이면 직업 선택 오버레이가 뜬다. 새 유저·기존
미전직 유저·전직 초기화 유저를 이 규칙 하나로 전부 커버한다.
별도 세이브 칸 없음.

## 흐름
- 로딩 완료 직후 게이트: promoClass 없으면 선택 화면 (닫기 불가, 스킵 없음)
- 카드 3장: 전사/궁수/법사 1단계 초상(captain_*.png) + 이름 + 한 줄 소개
- 선택 = promoClass 확정 (tier 1). 단장 외형 즉시 반영 — 궁수1·법사1
  시트가 실전 투입된다
- 훈련소 조건 충족 시 기존 전직 화면에서 그 길 2단계 승급 (promote 의
  "한 길만" 차단 그대로)
- 전직 초기화: promoClass=null → 선택 화면 재등장
- 선택 확정·전직 초기화 직후 **현재 스테이지 판을 처음부터 재시작**
  (진행도는 유지) — 전투 상태 꼬임 방지 (단장 확정 2026-08-27)

## 파일
main.js (선택 화면 + 게이트 + resetPromotion 연결 + 판 재시작),
index.html (카드 CSS), tutorial.json (연출 문서 기록)
