# v1.4.0 천둥 업데이트 — 에셋 프롬프트 (ChatGPT 이미지)

`에셋_생성_프롬프트.md` 3절 조립 공식 그대로. 한 장씩 생성, 만족할 때까지 재생성.
**기존 LR-01/LR-02 이미지를 같이 첨부하고** 첫 줄에 "Match the exact art style of the attached reference images." 를 붙이면 그림체가 맞는다.

| 파일 | 저장 위치 | 원본 규격 → 게임 규격 |
|---|---|---|
| LR-03/04/05 전투 | `game/public/assets/char/<ID>.webp` | 1:1 → 512×512, 투명 배경 |
| LR-03/04/05 도감 일러 | `game/public/assets/art/<ID>-ART.png` | 2:3 → 512×768 |
| PF-T1 / PF-T1G 테두리 | `game/public/assets/ui/<ID>.png` | 1:1 → 512×512, 가운데 투명 |

## 후처리 (Claude 가 한다)

1. 배경 제거: `node tools/cutbg.js` 또는 `python tools/fixbg.py`
2. 크기 맞춤 + webp 변환 (char/)
3. `python tools/trim.py` → `trim.json`
4. `python tools/autocut.py char LR-03` (04, 05) → `cutout/<ID>.json`
5. `npm run assets:manifest`, `npm run assets`
